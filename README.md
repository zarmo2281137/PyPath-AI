# PyPath AI — Навчальна платформа Python & AI Backend

Інтерактивна вебпрограма для навчання за 2-річним планом від нуля до Junior+ Python / AI Backend розробника (Етапи 0–10).

## Можливості
- **11 етапів / 48 уроків**: теорія, приклади коду, практичні завдання, посилання на документацію.
- **Акаунти та збереження прогресу**: реєстрація/вхід (`PBKDF2-HMAC-SHA256` + `HttpOnly` сесії), збереження пройдених тем, нотаток, результатів тестів, XP та серії днів у SQLite.
- **Міні-тести та тренажер співбесіди**: перевірка знань після кожної теми та картки з питаннями зі співбесід.
- **Вбудована Python Пісочниця**: запуск Python-коду прямо в браузері.
- **Фокус-таймер (Pomodoro)** та перемикач світлої/темної теми.

## Локальний запуск

```bash
python -m venv .venv
# Windows PowerShell:
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

Після запуску відкрийте `http://127.0.0.1:8000`.
